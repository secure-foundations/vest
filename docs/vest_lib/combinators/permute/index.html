Module permute 

Source
Expand description

Combinators for parsing permutations of sub-parsers.

Each Permute* combinator accepts any ordering of its components while its serializer always emits the declared order. That makes them deliberately malleable: distinct byte strings map to the same value, so NonMalleable and PSRoundTrip are not available. Soundness is, because reordering preserves the total length.

Only widths 2 to 5 are provided. The construction enumerates orderings, so the number of parse paths grows as N! (Permute4 has 24, Permute5 has 120).
