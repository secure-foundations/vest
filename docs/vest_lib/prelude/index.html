vest_lib

Module prelude 

Source
Expand description

This module re-exports the most commonly used items from Vest.

use vest_lib::prelude::*; would include the Verus prelude, Vest’s executable, specification and proof traits, as well as its format combinators.

In addition, some basic length and bytes-view broadcast lemmas are enabled automatically when vest_lib is imported.

View
Types used in executable code can implement View to provide a mathematical abstraction of the type. For example, Vec implements a view method that returns a Seq. For base types like bool and u8, the view V of the type is the type itself. Types only used in ghost code, such as int, nat, and Seq, do not need to implement View.
