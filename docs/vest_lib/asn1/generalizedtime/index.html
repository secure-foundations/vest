GeneralizedTime
GeneralizedTimeSpec
Logical specification of an ASN.1 GeneralizedTime value (X.680 clause 46). Consists of a calendar date (YYYYMMDD), local time of day, optional fractional seconds, and a timezone offset or Zulu UTC indicator.
