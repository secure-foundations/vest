Struct Size 

Source 
pub struct Size<const HAS_MIN: bool, const MIN: usize, const HAS_MAX: bool, const MAX: usize>;
Expand description

An ASN.1 SIZE interval.

Disabled bounds ignore their corresponding numeric const parameter. Keeping both flags explicit mirrors ASN.1’s MIN and MAX endpoints and avoids approximating an unbounded specification with a machine maximum.
