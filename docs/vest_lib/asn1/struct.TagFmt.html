Struct TagFmt 

Source 
pub struct TagFmt;
Expand description

ASN.1 tag format combinator.

Only the canonical DER form is accepted:

  • Tag numbers 0–30 must use the short (1-byte) form.
  • High tag numbers must have no leading zero in the base-128 encoding.
