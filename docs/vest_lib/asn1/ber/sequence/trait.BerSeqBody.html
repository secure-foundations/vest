Expand description

An EOF-terminated body for BER SEQUENCE and EXPLICIT wrappers.

Indefinite framing replaces the final Eof with EOC_END, consuming the marker without changing the body’s value type. Only the continuation is changed; complete child TLVs are left intact. Implementations follow Pair, Optional, and DefaultedFmt continuations; SuffixTagged<C, Eof, ()> provides the same transformation for EXPLICIT wrappers.
