BER end-of-contents marker and consuming unit-valued terminal.

EOC recognizes the exact marker 00 00 and returns its tag/length pair. EOC_END recognizes the same bytes but returns (), so BerSeqBody can replace an EOF terminal without changing the schema’s value type.
