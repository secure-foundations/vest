Struct DefaultedFmt 

Source 
pub struct DefaultedFmt<Field, Default, Rest, const DER: bool = true>(pub Field, pub Default, pub Rest);
Expand description

ASN.1 DEFAULT component with continuation.

The semantic value always contains the component value. On parsing, absence is replaced by default. On serialization, a value equal to default is omitted. DER additionally rejects an explicitly encoded default value.
