# Contributor design notes

These files record implementation history, proof-design experiments, and
scalability investigations. They are useful when changing Vest itself, but are
not the user guide or API reference and are not included in published crates.

- [`design.md`](design.md): the original `vest_lib` redesign notes.
- [`bits.md`](bits.md): bitfield combinator design.
- [`malleability.md`](malleability.md): survey of intentionally malleable formats.
- [`mutual_rec.md`](mutual_rec.md): sketches behind mutual-recursion lowering.
- [`codegen-execs.md`](codegen-execs.md): executable code-generation plan.
- [`asn1-scalability.md`](asn1-scalability.md): ASN.1 verification experiments.
- [`notes.md`](notes.md): assorted older development notes.
